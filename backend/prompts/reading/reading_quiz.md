## 要求
1. 生成 3-5 道单选题，覆盖文章的主旨、细节、推理等不同层次。
2. 每道题有 4 个选项（A/B/C/D），只有 1 个正确答案。
3. 每道题附带简要解析，说明为什么正确答案是对的。
4. 题目难度应匹配 {{ level }} 水平的英语学习者。
5. **严格以 JSON 数组格式输出**，不要包含任何其他文字。

## 输出格式
```json
[
  {
    "id": 1,
    "question": "题干文本",
    "options": ["A. 选项A", "B. 选项B", "C. 选项C", "D. 选项D"],
    "correct_answer": "A",
    "explanation": "解析文本"
  }
]
```

注意：id 从 1 开始递增，correct_answer 只填字母（如 "A"、"B"、"C"、"D"）。
